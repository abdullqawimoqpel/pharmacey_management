Pharmacy Management (minimal demo) for XAMPP
1. Place the 'pharmacy_management' folder inside XAMPP's htdocs.
2. Import database/pharmacy_db.sql into phpMyAdmin.
3. Open http://localhost/pharmacy_management/ in your browser.
Default users:
 - admin / admin123 (role: admin)
 - staff / staff123 (role: staff)
Notes: This is a minimal starter project with Arabic UI and Bootstrap placeholders.
